# Лабораторная 4 — файлы, CSV и отчёты

Скрипт без аргументов читает `data/Lab04/input.txt` и пишет `data/Lab04/report.csv`. Пути и кодировку можно задать флагами.

Кодировка по умолчанию utf-8, другая задаётся флагом `--encoding`, например `--encoding cp1251`. Если файла нет или кодировка не подходит, программа падает с понятной ошибкой (FileNotFoundError или UnicodeDecodeError) — ошибки намеренно не перехватываются.

Пустой входной файл ошибкой не считается: отчёт создаётся и содержит только строку заголовка `word,count`.

## Задание 1 — io_txt_csv.py

Три функции для работы с файлами. `read_text` читает текстовый файл целиком в заданной кодировке. `write_csv` пишет таблицу в CSV и ругается, если строки разной длины. `ensure_parent_dir` создаёт папку под файл, если её ещё нет. Своего вывода модуль не имеет — его работа видна по отчётам в заданиях ниже.

Файл: `src/Lab04/io_txt_csv.py`

## Задание 2 — базовый запуск

Читает текст из файла, считает частоты слов функциями из ЛР3, пишет отчёт `word,count` и печатает сколько всего слов, сколько уникальных и топ-5.

# Лабораторная 5 — JSON, CSV и XLSX

Конвертации между JSON, CSV и XLSX. Для XLSX нужен openpyxl, поэтому появились виртуальное окружение и `requirements.txt`.

Перед запуском:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Пути относительные, запускать из корня проекта. Кодировка везде UTF-8.

Решения, которые задание оставило на выбор:
- Колонки в CSV идут в порядке первого объекта, новые ключи добавляются в конец.
- Нет поля у объекта — в ячейке пустая строка.
- CSV только с заголовком не ошибка, получится пустой список.
- Значения из CSV всегда строки, поэтому JSON → CSV → JSON не вернёт исходные типы: 22 станет "22".

## Задание 1 — JSON ↔ CSV

Два преобразования в одном файле. json_to_csv собирает колонки как объединение ключей всех объектов и заполняет пропуски пустыми строками. csv_to_json делает из каждой строки словарь, пишет с читаемой кириллицей и отступами.

Запуск:
```
.venv/bin/python src/Lab05/json_csv.py
```

Файл: `src/Lab05/json_csv.py`
Скрин: ![задание 1](images/Lab05/01.png)

## Задание 2 — CSV → XLSX

Конвертирует CSV в Excel через openpyxl. Лист называется Sheet1, ширина колонок по самому длинному значению, но не меньше 8. Готовый файл читается обратно и печатается построчно — видно, что он не битый.

# Лабораторная 6 — CLI-утилиты на argparse

Две утилиты с подкомандами. Каждая подкоманда оборачивает функции, которые уже написаны в ЛР3 и ЛР5, своей логики в конвертерах нет.

Запуск всегда из корня проекта через `-m`, чтобы работали и импорты, и относительные пути к данным. Конвертер в XLSX требует openpyxl, поэтому запускать из виртуального окружения: `.venv/bin/python`.

У каждой подкоманды есть `--help`. Если не указать обязательный флаг, argparse сам печатает ошибку и подсказку по использованию. Если входного файла нет, программа падает с FileNotFoundError.

## Задание 1 — cat

Печатает файл построчно. С флагом `-n` строки нумеруются с единицы. Флаг без значения: есть `-n` — нумерация, нет — чистый вывод.

Запуск:
```
.venv/bin/python -m src.Lab06.cli_text cat --input data/samples/people.csv -n
```

Файл: `src/Lab06/cli_text.py`
Скрин: ![задание 1](images/Lab06/01.png)

## Задание 2 — stats

Считает частоты слов функциями из ЛР3: нормализация, разбиение на слова, подсчёт. Печатает сколько всего слов, сколько уникальных и топ. Размер топа задаётся флагом `--top`, по умолчанию 5, argparse сам приводит его к числу.

Запуск:
```
.venv/bin/python -m src.Lab06.cli_text stats --input data/samples/people.txt --top 5
```

Файл: `src/Lab06/cli_text.py`
Скрин: ![задание 2](images/Lab06/02.png)

## Задание 3 — конвертеры

Три подкоманды: json2csv, csv2json и csv2xlsx. Вызывают функции из ЛР5. Флаги у всех одинаковые: `--in` для входного файла и `--out` для выходного. Папка под результат создаётся, если её нет. Результаты лежат в `data/out/`.

Запуск:
```
.venv/bin/python -m src.Lab06.cli_convert json2csv --in data/samples/people.json --out data/out/people.csv
.venv/bin/python -m src.Lab06.cli_convert csv2json --in data/samples/people.csv --out data/out/people.json
.venv/bin/python -m src.Lab06.cli_convert csv2xlsx --in data/samples/people.csv --out data/out/people.xlsx
```

Файл: `src/Lab06/cli_convert.py`
